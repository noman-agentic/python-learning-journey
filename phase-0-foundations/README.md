# Phase 0 — Foundations Refresh

Covered: variables, data types, operators, conditionals, loops, functions, lists/tuples, dictionaries/sets, string manipulation, error handling (try/except).

## Mini-Project: Contact Cleaner & Validator

Cleans raw contact data (name/email/age), validates email format, handles invalid age input with try/except, and builds a list of contact dictionaries dynamically inside a single loop — a small simulation of pre-processing data before it reaches an AI agent workflow.

Run with:

    python mini-project/contact_cleaner.py
